# Corey Warden — Portfolio

**Live site: [coreyw7.github.io](https://coreyw7.github.io)**

I'm a backend and full-stack developer with a B.S. in computer science and a minor in math from the University of Arkansas. This site has case studies on my work at Centene, my senior capstone, and the software I'm building for nonprofits.

## How it's built

Plain HTML, CSS, and a little JavaScript, with no framework and no build step, hosted on GitHub Pages.

- **Travel-themed design.** Projects are styled as boarding passes, and my experience reads like a route map.
- **Light and dark themes** that follow your system setting.
- **Interactive travel map.** It uses [d3-geo](https://github.com/d3/d3-geo) and [world-atlas](https://github.com/topojson/world-atlas) to draw a dotted world map, with pins that open photo strips.
- **Responsive and accessible.** It works on phones, supports keyboard navigation, and respects reduced-motion settings.
